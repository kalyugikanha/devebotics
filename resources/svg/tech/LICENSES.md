Source: [Simple Icons](https://simpleicons.org) 16.36.0 (CC0-1.0). Only the path data was copied; each file was
rewritten as a single-path SVG with `fill="currentColor"`.

All names and logos are trademarks of their respective owners. They are shown only to identify technologies the
company works with. That does not imply endorsement, partnership or certification. Follow each owner's brand
guidelines (linked from simpleicons.org) when changing how they are displayed.

Icons whose Simple Icons entry carries a non-commercial or attribution licence (for example Vue.js, PHP, Angular,
Android, Rust, Jenkins) are intentionally **not** bundled. Logos withdrawn from Simple Icons at their owners' request
(for example AWS, Microsoft Azure, Power BI, Salesforce) are not bundled either. Those technologies are shown with a
neutral initials tile instead (`App\Support\Art\TechLogoRegistry`). Upload an official logo in
Admin › Technologies if you hold the rights to use it.
